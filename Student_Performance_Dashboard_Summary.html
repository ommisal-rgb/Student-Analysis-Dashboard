1. Overview

This assessment presents an interactive Tableau dashboard developed using the Student Performance dataset. The dashboard converts academic observations from 600 engineering students across various departments into concise visual summaries of overall grade distribution, cumulative GPA (CGPA), attendance patterns, study hours, semester progression trends, and the relationship between class attendance and academic achievement.

2. Dataset Description

The Student Performance Dataset is a comprehensive academic repository containing 600 records across 6 engineering branches (CSE, IT, ECE, ME, CE, EE) and 8 semesters. It encompasses 16 key demographic, behavioral, and academic performance attributes, including CGPA, attendance percentage, weekly study hours, midterm, assignment, and final exam scores, extracurricular participation, internet access, and passing status classifications. It is ideal for exploratory data analysis and interactive visual reporting.

Dataset Source: Academic Student Performance Repository – Tableau Project

3. Objective

  • Explore the distribution of student performance categories and passing statuses across the cohort.
  • Compare average CGPA, attendance percentage, and weekly study hours across engineering branches.
  • Identify broad semester-wise academic progression and grade stabilization patterns.
  • Examine the relationship between attendance percentage, study hours, and final CGPA.
  • Present multiple academic metrics in a single, interactive, easy-to-understand Tableau dashboard.

4. Dashboard Design

The dashboard uses a combination of categorical, comparison, trend, distribution, and relationship visualizations. This allows both high-level executive understanding and detailed branch-level comparison within one unified Tableau view.

5. Key Observations

Performance categories: The status distribution shows Pass as the largest category in the displayed dashboard (83.7%), followed by Academic Distinction (12.0%). At-Risk students represent a small portion (4.3%) requiring academic monitoring.

Attendance impact: Class attendance shows average values concentrated around 81.8%, with top performers maintaining over 85% attendance and securing an average CGPA of 8.12. Attendance below 65% resulted in a 78% risk category conversion rate.

Branch comparison: The branch comparison highlights consistent performance across engineering streams. Computer Science and Information Technology lead distinction rates at 14.2% and 13.8% respectively, supported by high assignment submission scores.

Study hours & activity balance: Weekly study hours range from 5 to 30 hours. Students dedicating 18–25 study hours per week combined with active extracurricular participation achieved higher exam scores (avg 78.4) than isolated study routines.

Academic progress trend: The semester trend rises from Semester 1 to peak in Semester 2 (avg 7.54 CGPA) before stabilizing steadily around the 7.40 range from Semester 4 through Semester 8.

Attendance–CGPA relationship: The scatter plot indicates a strong positive relationship: students with higher attendance percentages consistently achieve upper-tier CGPAs (8.0–10.0), while lower attendance correlates directly with reduced grade point averages.

6. Data Science / Tableau Techniques Demonstrated

  • Data aggregation using custom calculated measures such as average CGPA, weighted attendance rate, and pass percentage.
  • Categorical analysis and segmentation using calculated fields for risk levels and distinction tiers.
  • Ranking and Top-N branch comparison using dynamic bar charts and treemaps.
  • Longitudinal time-based analysis across 8 academic semesters using line trend visualizations.
  • Bivariate exploratory analysis using an attendance-vs-CGPA scatter plot.
  • Dashboard composition: multiple coordinated worksheets arranged into a single unified analytical view.
  • Use of appropriate visual encoding (color gradients, KPI cards, and box plots) to communicate distributions, comparisons, and correlations effectively.

7. Conclusion

The Tableau dashboard provides a compact visual summary of student performance observations and demonstrates how data visualization can transform a large, multi-variable dataset into actionable insights. The dashboard makes it easier to compare engineering branches, identify seasonal/semester grade progression, understand performance distributions, and explore relationships between behavioral and academic variables. Overall, the work demonstrates the use of Tableau as a practical tool for institutional analytics, exploratory data analysis, and data-driven storytelling.
